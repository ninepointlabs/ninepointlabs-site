Omarchy

Linux, opinionated and ready to make things

Omarchy is a beautiful, modern, opinionated Linux desktop built around Arch Linux and Hyprland. It brings together a carefully chosen workflow, sensible defaults, keyboard driven tools, and a cohesive visual system so the desktop gets out of the way and the work gets interesting.

Visit omarchy.org View the source

Why build for Omarchy?

Omarchy makes the Linux desktop a productive, hackable place to live. Its plugin and theme systems make it possible to add useful local tools without giving up the focused experience that makes the desktop special.

Projects from Nine Point Labs

Small, practical additions for a desktop that stays personal and under your control.

Ring Cameras

A local Ring camera browser for the Omarchy bar. It provides live view, snapshots, recent event history, and motion notifications, with playback handled by mpv.

Explore Ring Cameras on GitHub

Nostr Signer

A local key-custody daemon for Nostr. It encrypts an nsec at rest, signs through a Unix socket for trusted plugins, and supports NIP-46 requests with approval controls.

Explore Nostr Signer on GitHub

Ted Lasso Theme

A warm AFC Richmond-inspired theme with navy, gold, green, red, and blue accents, plus three wallpapers including the familiar BELIEVE sign.

Explore Ted Lasso Theme on GitHub
