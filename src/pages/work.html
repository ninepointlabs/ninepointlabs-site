Flagship

Omostrich

live QML Node

A local Nostr key custody daemon for Omarchy Linux, with one bar icon to go with it. Your private key lives in an encrypted vault on your own machine and never leaves the daemon. Unlock it, compose and post a note (Super+N works from anywhere), review NIP-46 signing requests from other Nostr apps, and lock it again. Auto-locks on a timer you pick.

It also runs a small MCP server exposing exactly two tools, status and publish, so my AI agents can post a note when I ask them to, and only then. They never see the key.

omostrich.com Source

Omostrich-DB

live Node nostrdb

The quiet sibling. A headless service that keeps a local copy of your own notes and the replies, reactions, and zaps they get, in an embedded nostrdb cache. It only ever knows your public key. It exposes MCP tools so an agent can answer "how did my notes do yesterday?" from local data instead of hitting relays.

Source

Persistwise

live paid Rails 8

An RSS longevity archiver. You keep writing wherever you already write. Persistwise watches the feed and keeps a durable copy of every post: local HTML, a Wayback Machine snapshot, and a pinned copy on IPFS. Rails 8, Hotwire, SQLite, Solid Queue. $40 a year for an archive, more if you want typeset PDFs.

persistwise.com About Persistwise

Autonomix

50 stars Flutter Go

A package manager for the apps that only ship as GitHub releases: AppImages, tarballs, single binaries. Add a repo, pick the asset, and it installs, tracks, and updates it. Like Obtainium, but for Linux. The Flutter desktop app is the most-starred thing I've made. The Go command-line version sat idle for a while and just got revived.

Omarchy and the Linux desktop

Nostr

Keys stay home

Nostr is an open protocol for social communication: many clients, many relays, and an identity that's a key pair you hold. My rule for everything I build on it is simple. The key never leaves the machine, and nothing posts unless I say so.

Writing and journaling

Tools for people who like to write

I keep a journal and a blog and I post short things in a few places. Every one of these exists because a tool I wanted didn't, or got in the way.

  • rjrnl A simple, human-friendly command-line journal. Ruby.
  • jrnl-droid A minimal Android client for jrnl.sh that plays nicely with sync.
  • Keystone Cross-platform bullet journal: tasks, notes, journal, Google Drive sync.
  • tfz Terminal RSS and Atom reader that renders the full article.
  • mb-cli A pretty CLI for posting to Micro.blog. Go.
  • sendit Post to Micro.blog and X at once. Desktop app and a CLI.
  • writeapp More Micro.blog tooling. Same itch.
  • Microblog theme Newspaper and parchment theme with separate Essays and Notes sections.
