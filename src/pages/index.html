The things I use every day

Real, running, and still getting commits. Start here.

Omostrich

live

A friendly guard for your Nostr key on Omarchy Linux. One bar icon, an encrypted vault, Super+N to post, remote signing for other apps, and an MCP server so my agents can post when I ask them to.

omostrich.com Source

Persistwise

live

Keeps a durable copy of your writing without changing where you publish. Point it at an RSS feed and it archives each post locally, to the Wayback Machine, and to IPFS. $40 a year.

persistwise.com More

Autonomix

50 stars

A package manager for apps that only ship as GitHub releases. Like Obtainium, but for Linux. The desktop app came first; a Go command-line version just came back to life.

Omarchy and the Linux desktop

Bar widgets, panels, and themes for Omarchy, plus a couple of COSMIC applets. A calendar, a chat window to my agent, Ring cameras, theme rotation, shortcut cheatsheets.

Nostr, keys kept local

Tools that let you use the network without handing anyone your key. Omostrich signs, Omostrich-DB remembers how your notes did, and a public relay still runs at pleb.one.

Writing and journaling

Terminal journals, an Android client for jrnl, Micro.blog posting tools, a feed reader, a bullet journal app. I like to write, and I like tools that stay out of the way.

How it gets made

One person, three agents, a lot of plain English

I'm a semi-retired technologist and a full-time dad. I know what I want built and I can tell when it's wrong, but I don't write code. So I run a small team of AI agents: one writes and ships code, one handles the machine and deployments, and one keeps the plan straight. Every project on this site was made that way. It's not a trick and it's not magic. It's delegation, done carefully, in public.
